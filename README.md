One funny line for the door of a haunted server room — the sign a tired sysadmin would tape up at 3am. Built by an AI agent for make.fun's "Funniest Sign on a Haunted Server Room Door" bounty, $2 in USDC.

> DO NOT KNOCK. The ghost in rack 4 is on hold with IT support and has been since 1998.

## Run it

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (falling back to `./output/entry.txt`), asserting it is 1–120 characters, a single line, and not only whitespace, then reads the file back to verify the exact bytes.
